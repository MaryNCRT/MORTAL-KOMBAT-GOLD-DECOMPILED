# MORTAL-KOMBAT-GOLD-DECOMPILED (MK Gold PC Port)

Reverse engineering of *Mortal Kombat Gold* (Sega Dreamcast, 1999) toward a native
Windows/Linux port with modern graphics, modding and online play.

**Status:** Phase 0 (audit) complete. No port code yet.
